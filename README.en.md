# homebrew-tap

Personal [Homebrew](https://brew.sh/) tap by [muzijin701](https://github.com/muzijin701) (macOS Apple Silicon & Linux x86_64).

## Usage

```sh
brew tap muzijin701/tap
brew install matlab-shell
```

## Formulae

- [`matlab-shell`](https://github.com/muzijin701/matlab-shell): Interactive terminal MATLAB CLI (`msh` / `matlab-shell`)
