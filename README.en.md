# homebrew-tap

Personal [Homebrew](https://brew.sh/) tap by [muzijin701](https://github.com/muzijin701).

## Usage

```sh
brew tap muzijin701/tap
brew install <formula>
```

## Formulae

- [`matlab-shell`](https://github.com/muzijin701/matlab-shell): Interactive terminal MATLAB CLI (macOS Apple Silicon & Linux x86_64)
- [`wx-mini-video`](https://github.com/muzijin701/wx-mini-video): WeChat Mini Program media sniffer and downloader TUI (macOS universal preview)
- [`wechat-channels-downloader`](https://github.com/muzijin701/wechat-channels-downloader): WeChat Channels video and image post downloader TUI (macOS & Linux x86_64)
