# homebrew-tap

[muzijin701](https://github.com/muzijin701) 的个人 [Homebrew](https://brew.sh/) 软件源。

## 使用方法

```sh
brew tap muzijin701/tap
brew install <软件名>
```

- [`matlab-shell`](https://github.com/muzijin701/matlab-shell)：终端交互式 MATLAB CLI（macOS Apple Silicon & Linux x86_64）
