# homebrew-tap

[muzijin701](https://github.com/muzijin701) 的个人 [Homebrew](https://brew.sh/) 软件源（支持 macOS Apple Silicon 与 Linux x86_64）。

## 使用方法

```sh
brew tap muzijin701/tap
brew install matlab-shell
```

- [`matlab-shell`](https://github.com/muzijin701/matlab-shell)：终端交互式 MATLAB CLI（`msh` / `matlab-shell`）
